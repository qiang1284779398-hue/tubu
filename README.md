# TrailKit 徒步导航

TrailKit 是一款面向徒步行程准备、装备管理与离线轨迹导航的 Android 应用。

## 当前版本
- Version: 1.1.0
- Application ID: `com.tubu.trailkit`
- Minimum Android: 8.0 (API 26)

## 导航能力
- 导入 GPX 轨迹与 GPX 途经点
- 导入栅格 MBTiles 离线地图（PNG/JPEG/WebP）
- GPX 轨迹叠加，已走/剩余路段区分
- GPS 实时定位、精度、海拔和速度显示
- GPS 到 GPX 线段投影匹配、进度与剩余距离
- 可调偏航阈值（20–300 m）与震动提醒（定位精度较差时抑制误报）
- 手机电子罗盘、路线方位和左右修正提示
- 自动跟随开关、回到当前位置、缩放和途经点定位
- 北向标记、动态比例尺和坐标复制
- 前台定位服务，屏幕关闭时保持导航定位
- GPS 轨迹记录，并导出 GPX 文件

## 地图格式
支持 MBTiles 中的栅格瓦片，数据库应包含 `metadata` 和 `tiles` 表。矢量 PBF/MVT 暂不支持。导入前请确认地图覆盖徒步区域、坐标与瓦片方案正确、来源授权允许离线使用，并在出发前断网测试。

## 使用流程
1. 创建徒步项目并导入 GPX。
2. 导入覆盖路线的 MBTiles 地图。
3. 打开“地图 / 轨迹导航”，检查起终点和途经点。
4. 开启 GPS，等待定位精度稳定。
5. 设置偏航提醒距离，按需要开启自动跟随。
6. 需要记录新路线时，开始记录；结束后停止并导出 GPX。

## 安全说明
TrailKit 是辅助工具，不是专业测绘导航设备，也不能保证 GPS 在峡谷、密林或恶劣天气下持续准确。电子罗盘需要远离磁性物体并按手机提示校准。请携带纸质地图、指北针和备用电源，并根据天气和现场状况判断路线。SOS 信息由用户确认后通过系统短信、电话或分享界面发送；应用不会自动联系救援机构。

## 构建
GitHub Actions 工作流会运行导航单元测试并构建 Debug APK。Debug APK 适合测试，不等于经过签名和发布审核的正式发行版本。
