# TrailKit 徒步导航

TrailKit 是一款面向徒步行程准备、装备管理与离线轨迹导航的 Android 应用。

## 当前版本
- Version: 1.2.0
- Application ID: `com.tubu.trailkit`
- Minimum Android: 8.0 (API 26)

## 导航能力
- 导入 GPX 轨迹与 GPX 途经点
- 导入栅格 MBTiles 离线地图（PNG/JPEG/WebP），自动核对 bounds、抽样检查 GPX 路线瓦片，并在缺瓦片时尝试父级缩放回退
- GPX 轨迹叠加，已走/剩余路段区分
- GPS 实时定位、精度、海拔和速度显示
- GPS 到 GPX 线段投影匹配、进度与剩余距离
- 可调偏航阈值（20–300 m）与震动提醒（定位精度较差时抑制误报）
- 手机电子罗盘，按当地磁偏角校正真北方位，并显示传感器精度与校准提示
- 路线方位角、前方 500 米内明显转弯距离、方向与角度提示、左右转向提示、可选中文语音播报前方转弯、途经点接近/到达、偏航以及 GPS 中断/恢复提醒；按路线进度选择下一途经点，显示直线距离、沿路线距离和方位，并提供到达震动提醒
- GPX 正向/反向导航、连续轨迹匹配、进度与剩余距离；导航方向和路线进度按项目保存
- 自适应 WGS84 经纬网、UTM 公制网格坐标和 DMS 度分秒坐标显示与复制
- 地图长按取坐标、创建持久自定义标记；标记列表可定位、复制坐标、重命名和删除
- 地图多点测距，显示分段测量路线、点序号和总距离
- 一键全览整条 GPX 路线、定位路线起点，自动计算合适的地图缩放
- 北向标记、动态比例尺、设备朝向箭头和海拔剖面当前位置指示；地图中心与缩放按项目和地图保存
- 实时速度、海拔、GPS 精度与更新时效、手机电量、低电量提醒和剩余时间估算
- 当前位置分享与求助坐标，支持 OpenStreetMap 位置链接
- GPX 路线导出（含逐点海拔和途经点），GPS 轨迹记录导出
- 前台定位服务，屏幕关闭时保持导航定位；每个徒步项目独立保存 GPS 记录，异常退出后尽量修复未闭合的 GPX 文件
- GPS 精度较差时抑制偏航误报；可调偏航阈值并提供震动提醒

## 地图格式
支持 MBTiles 中的栅格瓦片，数据库应包含 `metadata` 和 `tiles` 表。矢量 PBF/MVT 暂不支持。导入前请确认地图覆盖徒步区域、坐标与瓦片方案正确、来源授权允许离线使用，并在出发前断网测试。

## 使用流程
1. 创建徒步项目并导入 GPX。
2. 导入覆盖路线的 MBTiles 地图。
3. 打开“地图 / 轨迹导航”，检查起终点和途经点。
4. 开启 GPS，等待定位精度稳定。
5. 设置偏航提醒距离，按需要开启自动跟随。
6. 可长按地图添加标记，或保存当前位置为标记点；可切换反向导航。
7. 可导出当前路线 GPX，或记录新路线并导出 GPS 轨迹。

## 安全说明
TrailKit 是辅助工具，不是专业测绘导航设备，也不能保证 GPS 在峡谷、密林或恶劣天气下持续准确。电子罗盘需要远离磁性物体并按手机提示校准。请携带纸质地图、指北针和备用电源，并根据天气和现场状况判断路线。SOS 信息由用户确认后通过系统短信、电话或分享界面发送；应用不会自动联系救援机构。

## 构建
GitHub Actions 工作流会运行导航单元测试并构建 Debug APK。Debug APK 适合测试，不等于经过签名和发布审核的正式发行版本。
