# TrailKit 徒步导航

TrailKit 是一款面向徒步行程准备、装备管理与离线轨迹导航的 Android 应用。

## 当前版本
- Version: 1.6.0
- Application ID: `com.tubu.trailkit`
- Minimum Android: 8.0 (API 26)

## 主要能力
- 徒步项目、装备照片、价格、重量、打包状态和维护记录管理
- 装备分类重量统计、建议清单、清单分享和海报
- GPX 导入、轨迹预览、途经点、高程数据和路线反向导航
- GPS 实时定位、精度与时效提示、GPS 跳点过滤、路线匹配、偏航提醒
- 前台定位服务，屏幕关闭时保持导航；支持轨迹记录、恢复与 GPX 导出
- 电子罗盘、地图朝向、海拔剖面、坐标网格和自定义标记
- MapLibre 矢量/地形离线区域下载，分区域暂停与继续
- 栅格 MBTiles 导入、路线覆盖核验和缺失瓦片提示
- 原生 OpenGL ES 3D 地形浏览与 GPX 轨迹叠加
- 实景相机路线辅助、目的地天气和安全求助资料

## 数据安全与备份
- 相册和相机选取的装备照片会复制到应用私有目录，降低外部 URI 权限失效风险。
- MBTiles 导入先写入临时文件并验证数据库、格式、瓦片和元数据，确认有效后才替换旧地图。
- 删除徒步项目时会清理其导入 MBTiles 文件和 TrailKit 管理的 MapLibre 离线区域。
- 项目备份以 ZIP 保存项目数据、可读取的装备照片和导入的 MBTiles；旧版 JSON 备份仍可导入。
- MapLibre 独立离线区域数据库和 Esri 卫星影像浏览缓存不包含在 ZIP 备份中。更换设备后，需要重新下载这些区域。

## 地图格式
支持包含 `metadata` 与 `tiles` 表的栅格 MBTiles（PNG/JPEG/WebP）。矢量 PBF/MVT MBTiles 暂不作为导入地图支持。导入后请核对路线覆盖范围和缩放层级，并在出发前断网测试。

## 离线地图下载
- 按 GPX 路线走廊分段下载，降低超大矩形区域造成的流量浪费。
- 每个项目分别管理矢量与地形任务，支持暂停、页面退出后继续。
- 可清理指定项目的 TrailKit 离线下载区域，不会删除其他项目的区域。
- 卫星底图目前使用最多 512 MiB 的浏览缓存，不提供批量离线卫星下载。

## 使用流程
1. 创建徒步项目并导入 GPX。
2. 按需导入栅格 MBTiles，或在地图页面按路线下载离线矢量/地形区域。
3. 核对地图覆盖范围、缩放级别和路线抽样瓦片完整性。
4. 开启精确定位，等待 GPS 精度稳定后开始导航。
5. 根据需要开启偏航提醒、语音指引、轨迹记录和自动跟随。
6. 出发前进行断网测试，并携带纸质地图、指北针和备用电源。

## 安全说明
TrailKit 是辅助工具，不是专业测绘导航设备，也不能保证 GPS 在峡谷、密林或恶劣天气下持续准确。电子罗盘需要远离磁性物体并按手机提示校准。山区天气预报与营地实况可能不同。请携带纸质地图、指北针和备用电源，并根据天气和现场状况判断路线。SOS 信息由用户确认后通过系统短信、电话或分享界面发送；应用不会自动联系救援机构。

## 构建与验证
GitHub Actions 会运行导航/离线下载规划单元测试并构建 Debug APK。Debug APK 用于验证，不等于经过发布审核的正式发行版本。浏览器尺寸模拟和单元测试不等于在真实手机上验证 GPS、相机、传感器、离线断网导航、耗电与发热。
