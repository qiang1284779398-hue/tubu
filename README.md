# 徒步装备管家 · TrailKit

Android 徒步装备项目管理工具。

## 功能
- 创建多个徒步项目，记录项目名称、目的地和日期
- 为装备上传照片，记录分类、单价、数量和备注
- 自动汇总装备数量与总价值
- 一键生成户外风格高清装备清单海报，保存到手机相册
- 项目数据保存在本机

## 获取 APK
每次推送到 main 后，GitHub Actions 自动构建 Debug APK。
打开仓库的 **Actions** → **Build TrailKit APK** → 最新运行 → **Artifacts** → 下载 **TrailKit-debug-apk**。

## 技术
Kotlin、Jetpack Compose、Android MediaStore。
